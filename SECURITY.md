# Security Policy

## Scope

PaxofiCloud is a cloud commerce, control-plane, orchestration, and digital-infrastructure platform. Security issues affecting application code, authentication, authorization, tenant isolation, billing, payments, provisioning, provider integrations, infrastructure automation, CI/CD, or customer data are treated as security-sensitive.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities publicly in an issue, pull request, discussion, or other public channel.

Use GitHub's private vulnerability reporting/security advisory mechanism for this repository when available. Include enough information to reproduce and assess the issue, including affected component, impact, reproduction steps, and any relevant logs or proof-of-concept material that can be shared safely.

If private reporting is not available, contact a PaxofiCloud repository administrator privately through GitHub and request a secure reporting channel. Do not include credentials, API tokens, customer data, or other secrets in the initial report.

## Response expectations

Security reports are triaged according to impact and exploitability. Confirmed material issues may result in a mitigation, patch, configuration change, credential rotation, provider-side action, or temporary service restriction as appropriate.

## Supported versions

Only actively maintained PaxofiCloud releases and the current development baseline are expected to receive security fixes. Unsupported releases may require an upgrade before remediation can be provided.

## Disclosure

Please allow Paxofi Technologies to assess and remediate a reported vulnerability before public disclosure. Coordinated disclosure is preferred.
